# Kraken Sim — état préproduction V1.2

Cette branche est réservée à l'état fictif de la stratégie V1.2. **Aucun cycle n'a été lancé**, aucun solde ni performance n'est publié à ce stade.

Lors de l'activation autorisée, le workflow manuel publiera `sim_v12.db`, `public_state_v12.json` et `history/` ici en fast-forward uniquement. Le moteur V1.2 ne peut pas écrire dans `kraken-sim` ni dans `kraken-sim-state`.

Seule la décision explicite de Cyril peut autoriser les cycles, puis séparément un éventuel cron. Ce dépôt est public : ne jamais y publier de secret ou de donnée privée.
